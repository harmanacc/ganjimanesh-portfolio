# مهدیه گنجی‌منش — Portfolio

Static, Persian-first (RTL) personal portfolio. Built with Astro, deployed on
Cloudflare.

## Status

Phase 0 — brief and research. Six design demos live under `/demos/*`.

## Commands

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm run preview
```

## Docs

- `BRIEF.md` — positioning, content, decisions
- `references/` — stack, animation, inspiration and prompt research
- `assets-inbox/` — drop raw CV / photos / project shots here
