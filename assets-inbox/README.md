# assets-inbox

Drop raw files here. Nothing here is published as-is — files get renamed,
optimized (AVIF/WebP), and copied into `src/assets/` or `public/` later.

## Naming convention

```
cv-fa.pdf
cv-en.pdf
portrait-01.jpg          # high-res, unedited is fine
project-<name>-01.jpg
project-<name>-02.png
logo.svg
```

## What to include

- [ ] CV / résumé (PDF, Persian)
- [ ] Portrait photo (high-res; plain or transparent background preferred)
- [ ] Project images (art therapy / clinic, WordPress sites, research)
- [ ] Screenshots of WordPress sites (full-page if possible)
- [ ] Research titles, abstracts or slides
- [ ] Any logo / wordmark / brand colors

## Notes

- Client names are fine — we anonymize during the build, not here.
- Phone numbers or national IDs visible in documents: tell me, and I'll crop them.
- Videos: drop them anyway; we'll pick a poster frame and compress.
